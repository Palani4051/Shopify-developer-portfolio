SHOPIFY DEVELOPER PORTFOLIO

1. Keep index.html, style.css, and script.js in the same folder.
2. Open index.html in your browser, or use the VS Code Live Server extension.
3. Replace YOUR_EMAIL@example.com with your real email address.
4. Add your actual resume PDF to this folder and name it resume.pdf.
5. Add your LinkedIn and GitHub links when ready.
6. Review project descriptions and employment dates before publishing.
7. Project preview panels are CSS illustrations, not screenshots of the live themes.
